# Decode.io — Project Brief

## 1. Project Overview

**Project Name:** Decode.io

**Project Type:** Full-Stack Web Application

**Vision:** Build a competitive Python coding platform inspired by Chess.com and Monkeytype, where users practise programming, compete against friends, and develop consistent problem-solving habits.

## 2. Problem Statement

Students learning programming often practise in isolation and lack an engaging way to compete with friends, track consistent progress, and measure their coding skills.

Decode.io aims to make programming practice more interactive through coding challenges, real-time 1v1 battles, daily challenges, and gamified progression.

## 3. Target Users

- Students learning Python.
- Beginners improving their programming fundamentals.
- Coding enthusiasts who enjoy competition.
- Friends who want to practise programming together.

## 4. Core Features

### A. Python Problem Library and Practice Engine

- Browse problems by difficulty and topic.
- Write and run Python 3 solutions.
- Submit code for evaluation against test cases.
- View submission verdicts and execution results.
- Track solved problems and submission history.

### B. 1v1 Coding Battles

- Create private rooms and invite friends using a code.
- Solve the same problem independently.
- Synchronize the match countdown and timer.
- Determine winners using verified submissions.
- Support separate Casual and Ranked modes.
- Maintain match history and competitive ratings.

### C. Daily Challenges and Streaks

- Publish one shared daily coding problem.
- Record verified daily completions.
- Track current and longest streaks.
- Award XP and unlock achievements.
- Display progress through a user dashboard.

## 5. Technology Stack

- **Frontend:** React + TypeScript
- **Backend:** Java + Spring Boot
- **Database:** PostgreSQL
- **Data Access:** Spring Data JPA + Hibernate
- **Security:** Spring Security
- **Real-Time Communication:** WebSocket
- **Code Execution:** Isolated Python execution service
- **Version Control:** Git + GitHub

## 6. Core Principles

- Backend-controlled results and rewards.
- Secure execution of submitted Python code.
- Reliable storage of user progress and match history.
- Responsive, dark-themed user interface.
- Modular code with clear separation of responsibilities.
- Automated testing and documented setup instructions.

## 7. Future Enhancements

- Cooperative coding challenges.
- Public matchmaking and tournaments.
- Friends, teams and social features.
- Advanced statistics and personalized recommendations.
- Additional programming languages.

## 8. Definition of Success

The first release should allow a user to solve Python problems, compete against a friend in a 1v1 battle, and complete a daily challenge with persistent progress.

Casual matches, ranked matches, verified code evaluation, streak tracking, and rewards must follow clearly defined server-side rules.
